# Smart Assistant (SPMA) 2026

Cross-platform AI Assistant Backend & Dashboard for Construction & Engineering Project Managers.

## Features
- **Earned Value Management (EVM)**: CPI, SPI, S-Curves, Planned Value, Earned Value, Actual Cost.
- **Primavera P6 & Schedule Analysis**: CPM, Critical Path, Float, Lookahead.
- **QA/QC & Site Management**: NCR records, MIR inspection logs, Daily Site Reports.
- **AI Project Controls Agent**: Powered by Gemini & LangChain.
- **Executive PDF & Excel Reporting**: Automated report generation.

## Run Locally
```bash
python launcher.py
```
Open `http://localhost:8000`
