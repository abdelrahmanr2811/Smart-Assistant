# 👁️ AI Computer Vision & Automated Inspection System (نظام فحص الصور بالرؤية الحاسوبية)

An intelligent Computer Vision & Optical Inspection system powered by **Python**, **OpenCV**, and **Multimodal AI Vision Models**. Automatically inspects images, detects structural surface defects (cracks, corrosion, alignment errors), and extracts optical metrics with high precision.

نظام ذكي للرؤية الحاسوبية وفحص الجودة الآلي باستخدام بايثون وخوارزميات معالجة الصور ونماذج الرؤية بالذكاء الاصطناعي، لكشف العيوب السطحية، والتشققات، وفحص معايير الجودة تلقائياً.

---

## 🌟 Key Features (المميزات الرئيسية)

- 🔍 **Automated Defect Detection**: Detects surface cracks, corrosion, voids, and structural anomalies.
- 📐 **Dimensional & Edge Analysis**: Extracts contours, dimensions, and alignment variance.
- 🏷️ **AI Visual Classification**: Combines rule-based OpenCV filters with Multimodal AI Vision models for comprehensive inspection.
- 📊 **Detailed Inspection Reports**: Generates automated inspection logs with confidence score and severity classification.
- ⚡ **RESTful API Ready**: Async endpoints built on FastAPI for real-time camera stream or batch image upload.

## 🚀 Quick Start (التشغيل السريع)

```bash
# Clone repository
git clone https://github.com/abdelrahmanr2811/Smart-Assistant.git
cd ai_computer_vision_inspection

# Install dependencies
pip install -r requirements.txt

# Run server
python main.py
```
Open `http://localhost:8000/docs` for interactive API documentation.
