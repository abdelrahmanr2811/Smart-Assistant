📌 أولاً: هل الجهاز الآخر يحتاج لتثبيت أي برامج؟
------------------------------------------------
نعم، يحتاج فقط تثبيت برنامج واحد فقط وهو:
👉 بايثون (Python 3.11)
لأن النظام مبني عليه ولا يحتاج أي برامج أخرى إطلاقاً.

رابط التحميل المباشر للويندوز:
https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe

⚠️ أهم خطوة أثناء تثبيت بايثون:
في أول شاشة تظهر عند فتح ملف التثبيت، يجب وضع علامة صح في الأسفل على:
☑️ [ Add Python to PATH ]
ثم الضغط على Install Now.


🚀 ثانياً: كيفية تشغيل المشروع:
--------------------------------
اضغط مرتين (Double Click) على الملف:
   👉 START_SERVER.bat
   (أو RUN_SPMA.bat)

سيبدأ النظام تلقائياً ويفتح المتصفح على واجهة النظام:
   http://localhost:8000


📱 ثالثاً: التشغيل من الموبايل (على نفس شبكة الواي فاي):
--------------------------------------------------------
بمجرد تشغيل الملف، ستظهر لك في الشاشة السوداء رسالة توضح رابط الموبايل مثل:
   http://192.168.1.XX:8000
افتح متصفح الموبايل واكتب هذا الرابط ليفتح النظام مباشرة على الهاتف.
